Today, we'll be continuing the series of lectures on memory by focusing on what is called episodic memory and what can happen if this is not working properly. 今天，我们将继续记忆系列讲座，重点讨论所谓的“情景记忆”，以及这种记忆无法正常运作时可能出现的情况。⭐️【episodic memory = 情景记忆】
Episodic memory refers to the memory of an event or 'episode'. 情景记忆指的是人们对某个事件或“情节”的记忆。⭐️【refer to = 指的是】
Episodic memories allow us to mentally travel back in time to an event from the past. 情景记忆使我们能够在脑海中穿越时空，回到过去的某个事件。⭐️【travel back in time = 回到过去；穿越回某个时刻】
Episodic memories include various details about these events, for example, when an event happened and other information such as the location. 情景记忆包含有关这些事件的各种细节，例如事件发生的时间和地点等其他信息。
To help understand this concept, try to remember the last time you ate dinner at a restaurant. 为了帮助理解这一概念，请试着回想一下你最近一次在餐厅吃晚饭的经历。
The ability to remember where you ate, who you were with and the items you ordered are all features of an episodic memory. 能够记起自己在哪里用餐、当时和谁在一起以及点了哪些食物，这些都是情景记忆的特征。
Episodic memory is distinct from another type of memory called semantic memory. 情景记忆不同于另一种被称为“语义记忆”的记忆。⭐️【be distinct from = 与……不同】⭐️【semantic memory = 语义记忆】
This is the type of factual memory that we have in common with everyone else - that is your general knowledge of the world. 语义记忆是我们与其他人共同拥有的事实性记忆，也就是关于这个世界的一般知识。⭐️【factual memory = 事实性记忆】⭐️【have something in common with = 与……共同拥有某事物】
To build upon a previous example, remembering where you parked your car is an example of episodic memory, but your understanding of what a car is and how an engine works are examples of semantic memory. 在之前的例子上进一步说明：记得自己把车停在哪里属于情景记忆，而理解汽车是什么以及发动机如何运转，则属于语义记忆。⭐️【build upon = 在……基础上进一步发展／说明】
Unlike episodic memory, semantic memory isn't dependent on recalling personal experiences. 与情景记忆不同，语义记忆并不依赖对个人经历的回想。⭐️【be dependent on = 依赖于】⭐️【recall personal experiences = 回想个人经历】
Episodic memory can be thought of as a process with several different steps of memory processing: encoding, consolidation and retrieval. 情景记忆可以被视为一个包含多个记忆加工步骤的过程：编码、巩固和提取。⭐️【memory processing = 记忆加工】⭐️【encoding = 编码】⭐️【consolidation = 巩固】⭐️【retrieval = 提取】
The initial step is called encoding. 第一个步骤称为编码。
This involves the process of receiving and registering information, which is necessary for creating memories of information or events that you experience. 这包括接收和登记信息的过程，而要形成对所接收信息或亲历事件的记忆，这一过程必不可少。⭐️【register information = 登记／识别信息】
The degree to which you can successfully encode information depends on the level of attention you give to an event while it's actually happening. 你能在多大程度上成功编码信息，取决于事件发生时你对它投入了多少注意力。⭐️【the degree to which = ……的程度】⭐️【give attention to = 关注；投入注意力】
Being distracted can make effective encoding very difficult. 注意力分散会使有效编码变得十分困难。
Encoding of episodic memories is also influenced by how you process the event. 情景记忆的编码还会受到你处理该事件的方式的影响。
For example, if you were introduced to someone called Charlie, you might make the connection that your uncle has the same name. 例如，如果有人向你介绍一个名叫Charlie的人，你可能会联想到自己的叔叔也叫这个名字。⭐️【make the connection that = 建立联系；联想到】
Future recollection of Charlie's name is much easier if you have a strategy to help you encode it. 如果你采用某种策略来帮助自己编码这个名字，日后回想起Charlie的名字就会容易得多。⭐️【recollection = 回忆；回想】
Memory consolidation, the next step in forming an episodic memory, is the process by which memories of encoded information are strengthened, stabilised and stored to facilitate later retrieval. 记忆巩固是形成情景记忆的下一个步骤；在这一过程中，已经编码的信息记忆会得到强化、稳定和储存，以便日后提取。⭐️【facilitate later retrieval = 便于日后提取】
Consolidation is most effective when the information being stored can be linked to an existing network of information. 当需要储存的信息能够与现有的信息网络建立联系时，记忆巩固的效果最好。⭐️【be linked to = 与……建立联系】⭐️【an existing network of information = 现有的信息网络】
Consolidation makes it possible for you to store memories for later retrieval indefinitely. 记忆巩固使你能够无限期地储存记忆，以供日后提取。⭐️【indefinitely = 无限期地】
Forming strong memories depends on the frequency with which you try to retrieve them. 能否形成牢固的记忆，取决于你尝试提取这些记忆的频率。⭐️【the frequency with which = ……的频率】
Memories can fade or become harder to retrieve if they aren't used very often. 如果记忆不经常被使用，它们就可能逐渐淡化或变得更难提取。⭐️【memory fades = 记忆逐渐淡化】
The last step in forming episodic memories is called retrieval, which is the conscious recollection of encoded information. 形成情景记忆的最后一个步骤称为提取，也就是有意识地回想已经编码的信息。⭐️【conscious recollection = 有意识的回想】
Retrieving information from episodic memory depends upon semantic, olfactory, auditory and visual factors. 从情景记忆中提取信息取决于语义、嗅觉、听觉和视觉因素。⭐️【olfactory = 嗅觉的】⭐️【auditory = 听觉的】
These help episodic memory retrieval by acting as a prompt. 这些因素可以充当提示，帮助人们提取情景记忆。⭐️【act as a prompt = 充当提示】
For example, when recalling where you parked your car you may use the colour of a sign close to where you parked. 例如，在回想把车停在哪里时，你可能会借助停车位置附近某块标牌的颜色。
You actually have to mentally travel back to the moment you parked. 实际上，你必须在脑海中回到停车的那一刻。
There are a wide range of neurological diseases and conditions that can affect episodic memory. 多种神经系统疾病和健康状况都可能影响情景记忆。⭐️【a wide range of = 多种；范围广泛的】⭐️【neurological = 神经系统的】
These range from Alzheimer's to schizophrenia to autism. 这些疾病和状况包括阿尔茨海默病、精神分裂症和自闭症。⭐️【range from ... to ... = 涵盖从……到……】
An impairment of episodic memory can have a profound effect on individuals' lives. 情景记忆受损可能会对个人生活产生深远影响。⭐️【impairment = 损伤；功能障碍】⭐️【have a profound effect on = 对……产生深远影响】
For example, the symptoms of schizophrenia can be reasonably well controlled by medication; 例如，精神分裂症的症状可以通过药物得到较好的控制；⭐️【schizophrenia = 精神分裂症】⭐️【be controlled by medication = 通过药物得到控制】
however, patients' episodic memory may still be impaired and so they are often unable to return to university or work. 然而，患者的情景记忆可能仍然受损，因此他们往往无法重返大学或工作岗位。⭐️【however = 然而（话语功能：转折）】⭐️【be impaired = 受损】
Recent studies have shown that computer-assisted games designed to keep the brain active can help improve their episodic memory. 最近的研究表明，以保持大脑活跃为目的而设计的计算机辅助游戏，可以帮助患者改善情景记忆。⭐️【computer-assisted = 计算机辅助的】
Episodic memories can help people connect with others, for instance by sharing intimate details about their past: something individuals with autism often have problems with. 情景记忆能够帮助人们与他人建立联系，例如分享自己过去的私密细节，而自闭症人士通常难以做到这一点。⭐️【connect with others = 与他人建立联系】⭐️【intimate details = 私密细节】
This may be caused by an absence of a sense of self. 这可能是由于他们缺乏自我意识。⭐️【a sense of self = 自我意识】
This is essential for the storage of episodic memory, and has been found to be impaired in children with autism. 自我意识对于储存情景记忆至关重要，而研究发现，自闭症儿童的这种意识可能存在缺陷。
Research has shown that treatments that improve memory may also have a positive impact on children's social development. 研究表明，改善记忆的治疗也可能对儿童的社会性发展产生积极影响。⭐️【have a positive impact on = 对……产生积极影响】⭐️【social development = 社会性发展】
